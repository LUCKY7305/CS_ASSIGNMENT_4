2. THE EXACT MITIGATION IMPLEMENTED
--------------------------------------------------------------------------------
Mitigation Technique: Context-Aware HTML Entity Output Encoding
Implementation File: src/utils/encoder.js

Code Snippet:
  function encodeHTML(input) {
    if (input === null || input === undefined) return '';
    const str = String(input);
    return str
      .replace(/&/g, '&amp;')    // 1. MUST BE ENCODED FIRST: avoids double-encoding
      .replace(/</g, '&lt;')     // 2. Encodes '<': prevents entering Tag Open State
      .replace(/>/g, '&gt;')     // 3. Encodes '>': prevents premature tag closing
      .replace(/"/g, '&quot;')   // 4. Encodes '"': prevents attribute breakout
      .replace(/'/g, '&#x27;')   // 5. Encodes '\'': prevents attribute breakout
      .replace(/\//g, '&#x2F;');  // 6. Encodes '/': neutralizes closing sequences
  }

Application in Secured View (src/views/securedView.js):
  const safeQuery = encodeHTML(query);
  const reflectionHtml = `
    <div class="reflection-target-box">
      Query reflected in HTML response: <strong>${safeQuery}</strong>
    </div>
  `;

Why this specific mitigation works:
When the browser's HTML tokenizer parses the incoming byte stream from the server:
- Encountering raw `<` transitions the tokenizer from "Character Data State" to
  "Tag Open State", which instantiates an executable DOM node.
- Encountering the entity `&lt;` keeps the tokenizer in "Character Data State".
  The browser decodes the entity strictly for graphical rendering on screen,
  producing a safe DOM text node. The JavaScript engine is never invoked.

5. CONTEXT-SPECIFICITY NOTE (CRITICAL FOR VIVA)
--------------------------------------------------------------------------------
HTML entity encoding is the mathematically appropriate defense specifically for
an HTML Body Text Context (e.g., between <div>...</div> or <p>...</p>).

It is NOT universally sufficient across all web contexts:
- Attribute Context (e.g., <a href="...">): Requires URL scheme validation (blocking
  javascript: URIs) and attribute quoting.
- Script Context (e.g., <script>var x = "...";</script>): HTML entity encoding does
  not stop execution; JavaScript unicode escaping is required.
- CSS / Style Context: Requires strict alphanumeric property allowlisting.
- URL Parameter Context: Requires URL percent-encoding (encodeURIComponent).
